## Publish this repository with GitHub Pages

1. Upload `index.html` to the root of this repository.
2. Open **Settings → Pages**.
3. Under **Build and deployment**, select **Deploy from a branch**.
4. Choose branch `main` and folder `/ (root)`, then save.
5. GitHub will show the published website URL in the Pages settings. For this repository it will usually be:
   `https://nimish120493.github.io/Nimish-Pund/`

See the official [GitHub Pages guide](https://docs.github.com/en/pages/getting-started-with-github-pages/creating-a-github-pages-site).
